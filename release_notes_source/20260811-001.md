# SimpleRisk 20260811-001 Release Notes

## Security Issues
- Hardened output encoding and tightened server-side permission checks on report downloads, addressing findings from an external penetration test.
- Hardened a mail-related rate limit.
- Tightened permission enforcement on compliance test results.
- Tightened permission enforcement on uploaded file downloads so a file cannot be reached from a module it does not belong to.
- Added missing permission checks to two API endpoints.
- Aligned the permission required by dashboard widget data requests with the permission required by the page that hosts them, and gave a business-unit risk exposure widget an explicit permission where it previously declared none.
- Increased the strength of stored multi-factor authentication secrets.
- Updated the single sign-on libraries to versions that address published security advisories.
- The sign-in form now accepts credentials only from a posted request body, keeping them out of places a request URL is routinely recorded.

## New Functionality
- Added a Home dashboard as the default post-login landing page, with a Getting Started onboarding checklist and a redesigned, consistent set of Risk, Compliance, Governance, and Incident dashboards.
- Redesigned Define Control Frameworks as a framework list with its controls alongside, letting you record which controls apply to each framework and why, and generate a Statement of Applicability for any framework.
- Redesigned Define Tests: control tests can now recur on a fixed calendar cadence rather than only counting down from the last run, audits can require approval before they close with rejection back for rework, one test can be applied to many controls instead of being duplicated, and test history is viewable per test.
- Redesigned Self-Assessments to run against the Secure Controls Framework.
- Rebuilt the Connectivity Visualizer on an expanded entity graph that now includes exceptions, audits, vulnerabilities, and the risk and threat catalogues, with search, click-through exploration, and inline inspection of any item.
- Added an AI Capabilities Catalog so AI features can be enabled and discovered individually, and unified the AI settings into a single hub.
- Added an AI context graph and organization profile grounded in your GRC data, plus AI-suggested control tests with human review on the Define Tests page.
- Added a Model Context Protocol (MCP) server for external AI-assistant integration, including read-only discovery tools that let an assistant find controls needing attention, tests that are due, top risks, and the framework and control catalog — all gated by the same permissions that govern the underlying data.
- Ollama and other keyless local or self-hosted AI providers are now fully usable, and AI provider requests honor the configured web proxy.
- Emails that fail to send now raise a notification once delivery has been retried and given up, pointing to the Queue Monitor for per-message detail, with a configurable retention period on the Mail settings page.
- Customers with the Customization Extra can now replace the SimpleRisk logo and tagline with their own and publish a system use notice on the login screen, satisfying access-control requirements such as NIST 800-53 AC-8. An uploaded logo also appears in the top bar and on questionnaires sent to external respondents.
- Added an optional demonstration mode for operators running a shared, publicly accessible SimpleRisk instance. When enabled, SimpleRisk declines the self-service actions that would let one visitor disrupt the instance for everyone else. The setting is off by default and has no effect on a normal installation.

## Performance / Availability
- Improved activation performance of the Jira Integration Extra.
- Improved activation performance of the Advanced Search Extra.
- Improved reliability of Workflows Extra activation and deactivation.
- Encrypted Database activation and deactivation no longer get stuck indefinitely if interrupted.

## Aesthetics / User-Interface
- Added a collapsing sidebar and refreshed the navigation shell.
- Redesigned the login, password reset, and multi-factor screens.
- Control reference text written by AI is now attributed as such.

## SimpleRisk Extra Development
- Fixed an issue that prevented the Secure Controls Framework Extra from installing or updating against the SCF 2026.2 content release.
- Fixed Workflows Extra internal links breaking when SimpleRisk is installed in a subdirectory.
- Fixed Vulnerability Management configure forms not saving.
- Assessment invitation and result-share emails to external contacts are now delivered on instances using the Encrypted Database Extra.
- The Statement of Applicability can be downloaded as an Excel workbook or PDF, and the PDF now carries a running header and page numbers on every page.

## Bug Fix
- Fixed several issues that could prevent SimpleRisk from upgrading, including a defect that stopped the one-click upgrade from running at all and issues affecting instances upgrading from much older releases. Instances running an older version of PHP are now upgraded as far as that PHP version supports rather than being refused entirely, a damaged Upgrade Extra can now repair itself, and the upgrade screen reports progress reliably regardless of web server configuration. Database backups taken during an upgrade no longer require external tools and now appear on the Backups page. Also corrects several database schema differences between upgraded and newly-installed instances.
- Duplicate instance identifiers are now detected and repaired during upgrade.
- Fixed questionnaire file attachments duplicating on save and being lost on completion.
- Fixed a regression that could stop auto-save and file management from working on questionnaires sent to external respondents.
- Saving a self-assessment response no longer discards the fields the request did not mention — a comment is preserved when only the answer is sent, and the answer is preserved when only the comment is sent.
- Fixed several defects in the Assessments questionnaire API: files attached to a specific question are now visible on the result, multi-line comments keep their line breaks, submitting no longer reports a false error on success, permission denials return the correct status code, an unknown questionnaire token is reported as not found, uploading or deleting a result file now requires the same permission as viewing the result, and saving a new template returns the created template's ID.
- Fixed an issue where requiring multi-factor authentication for all users could prevent users from signing in.
- Fixed an issue where a user required to change their password at first login was returned to the change-password page instead of continuing to sign in, when multi-factor authentication was also enabled for their account.
- Resolved an error that could prevent multi-factor enrollment on some database configurations.
- Fixed Import Controls and Import Risks rejecting valid rows, mishandling blank cells, and re-submitting on refresh.
- Test dates submitted through the API are now accepted in either date format, and an invalid date is reported — in your language, naming the field at fault — instead of being ignored.
- The Default Desired Maturity preference is now applied to new controls, instead of the dropdown ignoring it.
- Fixed AI features returning no result with newer thinking-enabled models, and AI-suggested control test generation producing no proposed tests.
- Fixed a bug that could cause a fresh installation to fail when the database schema contained tables with foreign keys defined out of dependency order.
- Fixed a bug where the extra-stylesheet loader never matched real stylesheet files, and hardened the in-page localization helper so pages degrade gracefully instead of erroring when a string is missing.
- Updated the data grid library used across risk, compliance, reporting, questionnaire, and assessment tables.

## Documentation
- The User and Administrator Guides have been rewritten to focus on the user experience rather than internal implementation details, with screenshots refreshed against the current interface.
- The Submitting a Risk, Recording an Incident, and Assessments articles now include a complete reference for every field on their forms, correcting several field-label and required-field inaccuracies.
- The VirtualBox and VMware appliance installation guides are now maintained alongside the rest of the documentation, and the risk import guide gains a full spreadsheet-preparation section.

## Code Cleanup
- Removed unused build tooling files from the application directory.

## Language Updates
