# Retired install guides

These PDFs are the old SimpleRisk installation guides. They describe operating systems and releases that SimpleRisk no longer supports, or have been replaced by maintained articles in the SimpleRisk knowledge base. They are kept here for reference and are no longer linked from the SimpleRisk website.

**For a current install, start at https://www.simplerisk.com/download** and use the guide for your operating system.

## Where each one went

| Retired guide | Use instead |
|---|---|
| Ubuntu 22.04 | [Installing on Ubuntu 22.04](https://support.simplerisk.com/kb/01-13-installing-on-ubuntu-22-04), [24.04](https://support.simplerisk.com/kb/01-12-installing-on-ubuntu-24-04) or [26.04](https://support.simplerisk.com/kb/01-14-installing-on-ubuntu-26-04) |
| Ubuntu 13.04, 14.04, 16.04, 18.04, 20.04 | No longer supported. Use a supported Ubuntu LTS release above. |
| CentOS 7, CentOS 8 (PHP 8), RHEL (PHP 7 and PHP 8) | [Installing on RHEL 9](https://support.simplerisk.com/kb/01-16-installing-on-rhel-9) or [RHEL 10](https://support.simplerisk.com/kb/01-17-installing-on-rhel-10); the same steps work for CentOS Stream 9 and 10 |
| SimpleRisk Installation Guide, SimpleRisk LAMP Installation Guide | The article for your Linux distribution, listed at https://support.simplerisk.com/kb/01-02-installing-on-linux |
| Windows (XAMPP, WAMP) | Windows is not a supported platform. |
| VMware appliance, VirtualBox appliance | [Install SimpleRisk virtual appliance (VMware)](https://support.simplerisk.com/kb/install-simplerisk-virtual-appliance-vmware) and [(VirtualBox)](https://support.simplerisk.com/kb/install-simplerisk-virtual-appliance-virtualbox) |

The current guides for Debian 13, SLES 15 and SLES 16 are in the same knowledge-base chapter.

The Extra installation guides, the upgrade guide and the release notes stay in the root of this repository.
